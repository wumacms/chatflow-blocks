## 文档站补全（30 个组件页 + 4 篇新指南）

原 docs 只有 2 个组件页，且侧边栏已指向 4 个不存在的页面（features/pricing/faq/contact-form）。
PRD 8.3 要求「每个组件有独立文档页」，现已全覆盖。

**做法：文档由源码生成，不手写**
- 脚本 `scripts/gen-component-docs.mjs`（`pnpm docs:gen`）用 TypeScript AST 解析 `types.ts`，
  抽取接口/字段/可选性/JSDoc；从 `.vue` 抽默认值（`computed(() => ({ ...默认值, ...props.data }))`）与事件；
  从 `playground/src/App.vue` 抽真实可运行示例；扫描模板得出语义标签/aria/dark:/响应式断点
- **新增/改动组件后务必重跑 `pnpm docs:gen`**，否则文档会与代码脱节
- `docs/components/index.md` 的分类与用途是脚本的数据源之一，改动表格格式会被脚本解析不均：行格式必须
  `| \`Name\` | \`NameData\` | 用途 |`（允许 `[`Name`](/components/xxx)` 形式），否则重新生成会丢组件
- 新增组件页后需手动同步 `docs/.vitepress/config.mts` 侧边栏（脚本会打印分组 JSON 供复制）
- JSDoc 必须齐全：脚本末尾会列出缺注释的字段，当前 0 条

**本次顺带修的源码**
- 给 9 个完全无注释的 types.ts 和多个半缺的补齐 JSDoc（ComparisonTable/CourseList/IconWall/ImageText/
  Partners/Pricing/Team/Testimonials/TopImage 等）——注释即文档，缺了就生成空说明列
- Navbar 二级菜单原来只能 hover 展开，键盘 Tab 到不了：加 `group-focus-within:visible/opacity-100`
  与 `focus-visible` 焦点环，装饰 svg 加 `aria-hidden="true"`（对齐 PRD 8.4）

**新增指南页**：cli.md、auto-import.md、contracts.md（5 个通用类型 + 旧 Schema 映射表）、accessibility.md
